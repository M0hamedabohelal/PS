# منصة شرح وتصفح مقرر CS413: Problem Solving and Decision Making 🧠

منصة تعليمية حديثة ومريحة للعين، مخصصة لشرح وتصفح سلايدات مقرر **حل المشكلات واتخاذ القرار (CS413)** بكلية الحاسبات والمعلومات - جامعة طنطا، تدريس **د. مصطفى العشري**.

---

## 🌟 مميزات المنصة:
1. **تغطية شاملة 100% لجميع السلايدات (35 سلايد بالكامل)**:
   - المحاضرة 1 و 2: من سلايد 2 إلى سلايد 31 (28 سلايد).
   - المحاضرة 3: من سلايد 31 إلى سلايد 37 (7 سلايدات).
   - لا يوجد أي سلايد تم إغفالها أو اختصارها دون تفصيل كامل.

2. **تصميم مريح للعين (Eye Comfort Design)**:
   - 3 أوضاع للإضاءة:
     - 🌙 **الوضع الداكن المريح (Night Comfort)**: تباين ناعم لحماية العين أثناء المذاكرة الليلية.
     - 📜 **الوضع الدافئ (Sepia / Night Shift)**: يقلل الضوء الأزرق لراحة قراءة الكتب.
     - ☀️ **الوضع الفاتح الهادئ**: درجات رمادية وبيضاء ناعمة.

3. **الشرح بالعامية المصرية (بالبلدي) وأمثلة عملية**:
   - تبسيط المفاهيم الأكاديمية ونظم الذكاء الاصطناعي بلغة ممتعة وسهلة الفهم.
   - أمثلة واقعية من سوق العمل البرمجي، هندسة النظم، وحياة الشركات اليومية.
   - كبسولات تلخيص ونصائح للامتحانات لكل سلايد.

4. **وضعان للتصفح والعرض**:
   - 🗂️ **عرض البطاقات الكامل (Cards View)**: تصفح جميع السلايدات مع البحث والفلترة حسب المحاضرة أو الموضوع.
   - 🖥️ **وضع العرض التقديمي (Deck Presentation Mode)**: عرض سلايد بسلايد بأسهم الكيبورد وعرض ملء الشاشة.
